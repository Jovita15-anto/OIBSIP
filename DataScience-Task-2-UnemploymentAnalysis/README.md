# Unemployment Analysis in India

## 📌 Project Overview

This project analyzes unemployment trends in India using Python and data analysis techniques.

The analysis focuses on unemployment rates across different regions, rural and urban areas, and changes over time. It also explores the relationship between unemployment rate, estimated employment, and labour participation rate.

## 🎯 Objectives

- Analyze unemployment rates across different regions.
- Compare unemployment between rural and urban areas.
- Study unemployment trends over time.
- Examine the relationship between unemployment and labour participation.
- Visualize important patterns using charts.
- Calculate and interpret correlations between numerical variables.

## 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Analysis Performed

### 1. Data Cleaning
- Loaded the unemployment dataset.
- Checked the dataset structure.
- Handled missing values.
- Converted date information into a suitable format.

### 2. Exploratory Data Analysis

The project includes:

- Summary statistics
- Distribution of unemployment rate
- Average unemployment rate by region
- Rural vs Urban unemployment comparison
- Unemployment rate over time
- Unemployment vs Labour Participation Rate
- Correlation analysis
- Correlation heatmap

## 🔍 Key Insights

- The average unemployment rate is higher in urban areas than in rural areas.
- The unemployment rate increased sharply during April and May 2020 in the dataset.
- Haryana and Tripura show relatively high average unemployment rates in this dataset.
- The correlation between unemployment rate and labour participation rate is almost zero (0.0026).
- Unemployment rate and estimated employment have a weak negative correlation (-0.22).

## 📈 Conclusion

This analysis demonstrates how Python, Pandas, Matplotlib, and Seaborn can be used to clean, explore, visualize, and interpret unemployment data.

The project provides insights into regional, geographical, and time-based patterns in unemployment within the dataset.
