# 📊 Oasis Infobyte Data Science Internship

This repository contains the projects completed during my **Data Science Internship at Oasis Infobyte (OIBSIP)**.

The projects cover different areas of Data Science and Machine Learning, including classification, data analysis, regression, and NLP.

**Concepts Used:**

- Model Evaluation
